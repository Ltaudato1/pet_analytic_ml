# Реализация алгоритмов классического машинного обучения
Алгоритмы реализуются на чистом NumPy и, иногда, Pandas

## На данный момент реализовано:
### Линейные модели:
- Линейная регрессия
- Логистическая регрессия
- SVM (Машина опорных векторов)

### Метрические алгоритмы:
- KNN Classificator (Метод ближайших соседей) взвешенный
- KNN Regressor (Метод ближайших соседей) взвешенный
